# «Почему API отвечает 429?» — сценарий ролика

Человекочитаемая версия `film.js` и `text/ru.js` (держать в согласии). Диалог: **Вера** (she — объясняет,
основной голос Aoede) и **Макс** (he — спрашивает, голос Puck). Длительность — около 2,5 мин (en 2:27 — основной язык, ru 2:24).

Машина (`../figure.js`) работает весь ролик без остановок — это постоянный слой под сценами. Расписание
(когда приходят запросы) строится в `film.js → plan()` от реплик: запросы приезжают к словам, о которых
говорят, а монеты падают честно раз в 2 с. Все числа в кадре — из модели `../model.js`.

| # | Сцена | Реплики (суть) | Машина | Камера / в кадре |
|---|---|---|---|---|
| — | Вопрос | Макс: скрипт получает 429 — кто меня считает? · Вера: ведро с жетонами, я собрала его в железе | ровный поток раз в 1,6 с — запас тает | общий план; заголовок «Почему API отвечает 429?», плашка `HTTP/1.1 429` |
| 01 | Ведро | Вера: магазин на 5 монет — ведро, 5 — ёмкость b · Макс: откуда монеты? | пара запросов забирает монеты (чтобы было куда падать) | наезд на магазин; булавки «ведро», «ёмкость b = 5» |
| 02 | Пополнение | Вера: часы — раз в 2 с падает монета, r = 0,5/с · Макс: а если полный? · Вера: заслонка, лишняя — в стакан, копить нельзя | монеты падают в магазин, потом — мимо, в стакан переполнения | жёлоб и часы → заслонка и стакан; булавки |
| 03 | Запрос | Вера: запрос едет по ленте, толкатель кладёт нижнюю монету; есть монета — 200 · Макс: один запрос — один жетон | запросы раз в 2,6 с, все проходят | наезд на место выдачи; «1 запрос = 1 жетон», «200 OK» |
| 04 | Всплеск | Макс: а десять разом? · Вера: пять из запаса, пока едут — капнет ещё одна, остальные — в лоток 429 | 10 запросов через 0,35 с сразу после монеты: 6 пропущено, 4 отказа | общий план; живые счётчики 200 / 429, «5 из запаса + 1 подкапала» |
| 05 | В среднем | Макс: а по запросу в секунду, но долго? · Вера: сначала запас, потом ровно r; итог — не больше b + r·T | 1 запрос/с 16 с: сначала все, потом через раз | машина слева, справа — живой график «пропущено» против b + r·T, формула |
| 06 | Две ручки | Макс: у лимита две ручки? · Вера: b — всплески, r — средний поток; получил 429 — жди Retry-After | пара запросов | магазин и часы; «b — сколько разом», «r — сколько в среднем», ответ сервера с `Retry-After: 2` |
| — | Финал | Макс: пойду научу скрипт ждать | — | отъезд; итог: b, r, b + r·T; «модель живая — на странице» |

## Как пересобрать

```bash
cd explainers/token-bucket/video
make preview                    # живой плеер (http://127.0.0.1:8790/…)
make voice                      # озвучка en — основной язык (OPENROUTER_API_KEY); make voice LNG=ru — русская
make video video-cc             # MP4 16:9 и вертикальный с субтитрами в кадре → out/
make video video-cc LNG=ru
make cover; make cover LNG=ru   # обложки для Reels
make web                        # лёгкие 720p-версии для лендинга → out/web/; потом make dist в корне
```
