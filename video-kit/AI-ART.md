# Ролики с ИИ-картинками и сквозными персонажами

Концепция и инструкция для роликов, где кадры — сгенерированные иллюстрации (история с
героями), а не только вёрстка инфографики. Первый такой проект —
[`../karkas-house/video`](../karkas-house/video) («Три поросёнка 2.0»).

## Что меняется по сравнению с инфографикой

| | Инфографика (e-acc, pilates) | Ролик с ИИ-картинками |
|---|---|---|
| Кадр | HTML/SVG, рисуется кодом | ИИ-иллюстрация + HTML-слой поверх |
| Движение | анимация каждой детали | медленный наезд/панорама (Ken Burns), лёгкая тряска, наплывы; детали — в HTML-слое |
| Текст в кадре | часть вёрстки | только HTML поверх картинки: ИИ не пишет кириллицу надёжно, а текст должен совпадать с голосом и переводиться |
| Источник истины | код | код + файлы картинок в git (генерация не детерминирована: удачный кадр — ценность) |

Звук, субтитры, плеер, рендер — те же. Картинки — ещё один «кеш» рядом с репликами озвучки.

## Главная проблема — одинаковые герои на всех кадрах

Модель рисует каждый кадр заново. Если просто описывать «розовый поросёнок в каске», на
каждом кадре будет новый поросёнок. Решение — **библия проекта** и **референсы**:

1. **Стиль** — один текстовый фрагмент (техника, свет, палитра, «без текста»), добавляется в
   каждый промпт.
2. **Листы-референсы (refs)** генерируются первыми и одобряются глазами:
   - **персонаж** — лист разворота (turnaround): один герой четыре раза — спереди, ¾, сбоку,
     сзади, на нейтральном фоне. Плюс короткое каноническое описание `look` («розовый поросёнок,
     жёлтая каска, рыжий комбинезон…»);
   - **локация / предмет** — «лист» объекта с 2–3 ракурсов (дом из каркаса, кирпичная стройка).
3. **Кадры (shots)** генерируются с референсами: в запрос прикладываются картинки листов, а в
   начало промпта автоматически пишется легенда: «Image 1 — Наф-Наф: <look>; Image 2 — …
   Keep their appearance exactly as in the references». Двойная привязка — картинкой и словами.
4. **Зависимости.** Отпечаток кадра включает содержимое файлов его референсов: перегенерировали
   лист персонажа — устарели все кадры с ним (это и есть консистентность). Удачный кадр,
   который трогать нельзя, помечается `lock: true` — тогда он не перегенерируется, а только
   отмечается как устаревший.

Проверено на Seedream 5.0 Flash (OpenRouter): лист разворота 2048×1366 и кадр 9:16 1152×2048 —
по $0.018 и 20–40 с за картинку, до 14 референсов в запросе. Персонаж с листа переносится в
сцену узнаваемо (одежда, аксессуары, пропорции).

### Практические правила промптов

- Персонажей различать **силуэтом и аксессуарами** (каска, очки, планшет, шапка), а не оттенком
  кожи: у пластилиновых поросят он одинаковый.
- В кадре — не больше 3–4 героев; каждого упоминать в промпте по имени из легенды.
- Композиция под вертикаль: «главное — в нижних двух третях, верх спокойный» — там заголовок; низ
  (≈330 px) закрывают интерфейс Reels и субтитры.
- Всегда: `no text, no letters, no logos` (цифры и надписи — в HTML).
- Листы — на плоском фоне цвета палитры, без теней-окружения: так модели проще «вырезать» героя.
- Если кадр нужен «пополам» (сплит-экран), генерировать две картинки нужного формата (`1:1`),
  а не одну с двумя половинами.

## Пайплайн

```
art.js (библия)  ──make art──►  art/refs/*.jpg ─┐   (листы: смотрим, правим, фиксируем)
                                                 ├─► art/shots/*.jpg  ─► film.js (сцены) ─► make video-cc
                                art/art.json  ◄──┘   (отпечатки, seed, цена; art/index.html — галерея)
```

1. **Библия** — `art.js` проекта: модель, стиль, `refs` (персонажи, локации), `shots` (кадры).
2. `make art DRY=1` — что будет сгенерировано и сколько стоит; `make art` — генерация
   (референсы раньше кадров, параллельно до 4 запросов), только новое и изменённое.
3. Смотрим `art/index.html` (галерея: листы, кадры, промпты, цена; `make preview` → `/art/`).
4. Не понравилось:
   - поправить промпт → `make art` (перегенерируется он и всё, что от него зависит);
   - тот же промпт, другая попытка → `make art-redo ID=hook` (новый seed; старый файл — в `art/takes/`);
   - выбрать из нескольких → `make art-takes ID=hook N=3`, посмотреть в галерее, затем
     `make art-pick ID=hook SEED=…`.
5. Сцены (`film.js`) берут картинки по id: `shot('hook')` → `<img class="shot" src="art/shots/hook.jpg">`,
   двигают их `ken()` и кладут поверх HTML-надписи, цифры, плашки.
6. Озвучка, рендер, обложка — как обычно (`make voice video-cc`, `make cover`).

Картинки лежат в git (`art/refs`, `art/shots`, `art/art.json`); `art/takes/` — черновики, не в git.

## Библия: `art.js`

```js
import { character, place } from '../../video-kit/lib/art.js';

const STYLE = 'cute 3D clay / plasticine animation style, soft studio light, pastel palette …';

export default {
  model: 'bytedance-seed/seedream-5-0-flash',
  resolution: '2K',
  style: STYLE,                       // добавляется в конец каждого промпта
  refs: {
    nifnif: character({ name: 'Nif-Nif', look: 'chubby pink piglet, light-blue denim shirt …' }),
    house:  place({ name: 'frame house', look: 'modern Scandinavian frame house …' }),
  },
  shots: {
    hook: { aspect: '9:16', refs: ['nifnif', 'house'], prompt: 'Nif-Nif lies in a deck chair …' },
    // seed: 7 — зафиксировать; lock: true — не перегенерировать; n: 'note' — заметка в галерее
  },
};
```

`character()` и `place()` (`lib/art.js`) собирают промпт листа разворота; кадр-лист можно
описать и вручную (`{ aspect: '3:2', prompt: '…' }`). У любого элемента могут быть `refs` —
например, групповой лист «все герои рядом» для масштаба, собранный из листов каждого.

## Как оживлять неподвижные кадры

- **Ken Burns** — `ken(img, t, t0, t1, { from: { s: 1.12, y: 3 }, to: { s: 1.02 } })`: наезд или
  отъезд с панорамой, на всю сцену. Масштаб не меньше 1, сдвиг (в % кадра) — не больше запаса масштаба.
- **Акценты на словах** — как в инфографике: `s.sfx(a.at('шашлык'), 'pop')` + появление плашки,
  цифры, стрелки поверх картинки в этот момент.
- **Тряска / удар** — короткое смещение картинки на слове («дует» → `shake`).
- **Сплит-экран** — две картинки 1:1 сверху и снизу, разные траектории наезда.
- **Плашки** — текст всегда на подложке (полупрозрачной или цветной), чтобы читался на любой картинке.

## Несколько голосов

Реплику можно отдать другому голосу: `s.say('«Да его ж ветром сдует!»', { voice: 'wolf' })`, а в
`voice.config.json` — `"voices": { "wolf": { "voice": "Algenib", "instructions": "…" } }`.
Кеш, проверка распознаванием и сведение — как для основного голоса; в субтитрах у такой фразы
атрибут `data-voice="wolf"` (можно покрасить в `scenes.css`).
